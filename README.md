# One Letter: Coffee or Tea

One letter, **A** — coffee. A is the first letter and the top grade, and coffee is the bolder, more vivid drink: dark, hot, and alive, where tea is calm. The program writes exactly that single character to `/output/entry.txt`, no newline, no explanation.
